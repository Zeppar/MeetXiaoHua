# 在微信开发者工具 → 云开发 → 云函数 api → 配置 → 环境变量 中添加：
# 也可写在同目录 secrets.local.js（已 gitignore，勿提交）
#
# ========== 识别厂商 ==========
# RECOGNIZE_PROVIDER=baidu
# 可选：baidu（默认）| tencent
#
# ========== 抠图厂商 ==========
# MATTING_PROVIDER=baidu
# 可选：baidu（百度智能抠图，默认）| tencent（人像分割，可被小程序单次覆盖）
#       | rembg（自建）| local（小程序洪水填充兜底）
# 小程序「百度/腾讯」模式会在请求里传 provider，不依赖这个默认值也能对比
#
# ========== 百度 ==========
# 动物识别应用：
# BAIDU_API_KEY=识别应用的API Key
# BAIDU_SECRET_KEY=识别应用的Secret Key
#
# 智能抠图应用（可与识别不是同一套；不填则回退上面）：
# BAIDU_MATTING_API_KEY=抠图应用的API Key
# BAIDU_MATTING_SECRET_KEY=抠图应用的Secret Key
#
# 识别应用列表：https://console.bce.baidu.com/ai/#/ai/imagerecognition/app/list
# 图像处理应用列表：https://console.bce.baidu.com/ai/#/ai/imageprocess/app/list
# 开通「动物识别」：https://ai.baidu.com/tech/imagerecognition/animal
# 开通「智能抠图」：https://ai.baidu.com/tech/imageprocess/segment
#
# ========== 百度智能抠图参数（可选项很少）==========
# BAIDU_MATTING_METHOD=auto
# BAIDU_MATTING_REFINE_MASK=true
# BAIDU_MATTING_RETURN_FORM=rgba
#
# ========== rembg 自建 ==========
# REMBG_URL=http://你的公网IP:7000
# REMBG_MODEL=u2net_animal
# REMBG_ALPHA=false
# REMBG_AF=240
# REMBG_AB=10
# REMBG_AE=10
# 常用模型：u2net_animal / isnet-general-use / u2net
# 注意：云函数要能访问该地址（需公网或 VPC），不要填 127.0.0.1
# 本机开发者工具试用见 miniprogram/constants/matting-local.js
#
# ========== 腾讯云（保留，切换 RECOGNIZE_PROVIDER=tencent 启用）==========
# TENCENT_SECRET_ID=你的SecretId
# TENCENT_SECRET_KEY=你的SecretKey
# TENCENT_REGION=ap-guangzhou
#
# 密钥：https://console.cloud.tencent.com/cam/capi
# 开通图像识别：https://console.cloud.tencent.com/tiia
